# Шрифты для графиков

В каталоге лежат два файла:

- `DejaVuSans.ttf` — обычное начертание;
- `DejaVuSans-Bold.ttf` — полужирное начертание.

Они используются модулем `src/render/theme.py` для подписей на графиках и
схемах. Шрифт поставляется вместе с проектом, поэтому русские подписи
выглядят одинаково в Windows, Linux, macOS и в Docker-контейнере — без
установки системных шрифтов.

## Если шрифтов нет

`theme.py` ищет шрифт по списку путей: сначала в этом каталоге, затем в
системных каталогах DejaVu/Liberation/Noto (Linux), `C:/Windows/Fonts`
(Windows) и `/System/Library/Fonts` (macOS). Если подходящий шрифт не найден,
подписи автоматически транслитерируются латиницей, чтобы графики оставались
читаемыми.

## Замена

Можно положить другой TrueType-шрифт с поддержкой кириллицы, заменив файлы
`DejaVuSans.ttf` и `DejaVuSans-Bold.ttf`. Имя файлов должно остаться прежним,
либо путь нужно изменить в `src/render/theme.py` (`REGULAR_FONT`, `BOLD_FONT`).
