# Методика экспериментов

Документ описывает исследовательскую часть: вопрос, гипотезу, переменные,
метрики, параметры по умолчанию, порядок проведения и ограничения.

## 1. Исследовательский вопрос

> Как вероятность аппаратных ошибок и количество операций в квантовой схеме
> влияют на распределение результатов измерений и достоверность вычислений?

## 2. Гипотеза

При увеличении вероятности ошибок и/или числа операций отклонение
наблюдаемого распределения от идеального в среднем возрастает; характер
влияния зависит от типа ошибки и структуры схемы.

**Гипотеза не считается подтверждённой заранее.** Программа выдаёт данные, а
вывод делает пользователь: сравнивает наклоны кривых, разброс между
повторами и положение относительно шумового уровня.

## 3. Переменные

### Независимые

| Переменная | Обозначение | Диапазон по умолчанию |
|---|---|---|
| Вероятность bit-flip | `p_bit_flip` | 0 … 0,2 с шагом 0,01 |
| Вероятность phase-flip | `p_phase_flip` | 0 … 0,2 с шагом 0,01 |
| Вероятность ошибки считывания | `p_readout` | 0 … 0,2 с шагом 0,01 |
| Число операций (глубина) | `N_ops` | 2 … 20 с шагом 2 |
| Число измерений | `shots` | 100 … 20 000 (по умолчанию 1000) |

### Зависимые

| Показатель | Определение |
|---|---|
| TVD | `0,5 · Σ|P_ideal(x) − P_observed(x)|` |
| Средний TVD в точке | среднее по повторам |
| Стандартное отклонение | выборочное, `ddof = 1` |
| 95 % ДИ | `mean ± 1,96 · σ / √repeats` |
| Вероятность целевого результата | частота выбранной строки |
| Доля успешных запусков | то же для целевой строки (для шумового режима) |

### Фиксируемые (контролируемые)

Схема, состав операций, измеряемые кубиты, число повторов и shots внутри
серии, базовый seed, версия модели ошибок.

## 4. Виды серий

### 4.1. TVD от вероятности bit-flip

Схема выполняется при `p` от 0 до 0,2. Включён только канал вентилей
bit-flip; phase-flip и readout выключены. Точка `p = 0` показывает шумовой
уровень, создаваемый конечным числом измерений.

### 4.2. TVD от вероятности phase-flip

Аналогично, но включён только phase-flip. Для схемы Белла без `H` после места
ошибки кривая остаётся на уровне шума: `Z`-ошибка не видна в Z-базисе. Для
схемы `H–Z–H` (демо `phase_demo`) фазовые ошибки приводят к изменению
распределения. Это различие — предмет исследования, а не ошибка.

### 4.3. TVD от вероятности ошибки считывания

Включён только readout. Схема может быть минимальной (например, `X`), тогда
видно, как искажается почти детерминированный результат.

### 4.4. TVD от числа операций (глубины)

К базовой схеме добавляются пары `CNOT(control=0, target=1)`. Пара CNOT в
идеале равна тождественному преобразованию, поэтому идеальное распределение
не меняется, а число операций растёт. Рост TVD отражает накопление ошибок.
Вероятность ошибки фиксирована (по умолчанию `p = 0,02`, канал bit-flip).

### 4.5. Сравнение каналов ошибок

Одна и та же схема запускается отдельно с bit-flip, phase-flip и readout при
одинаковых `shots`, `repeats` и `seed`. Сравнение показывает, что вклад
канала зависит от схемы и базиса измерения.

### 4.6. TVD от числа измерений (shots)

Схема с фиксированной вероятностью ошибки измеряется разным числом shots
(по умолчанию 100, 250, 500, 1000, 2000, 5000, 10 000). TVD считается
относительно теоретического распределения, поэтому при малом числе измерений
в метрику входит статистический разброс.

На графике две кривые: TVD при выбранной ошибке и шумовой уровень (идеальная
выборка при тех же shots). Шумовой уровень убывает примерно как `1/√shots`,
а кривая с ошибкой выходит на плато: когда статистический вклад становится
меньше вклада ошибки, дальнейшее увеличение shots перестаёт улучшать
соответствие идеальному распределению. При `p = 0` обе кривые совпадают.

## 5. Параметры по умолчанию

| Параметр | Значение | Источник |
|---|---|---|
| shots на запуск | 1000 | рекомендация ТЗ |
| Число повторов | 10 | не менее 10 по ТЗ |
| Сетка вероятностей | 0; 0,01; …; 0,20 (21 точка) | пример ТЗ |
| Глубина | от 2 до 20 операций, шаг 2 | выбрано для наглядности |
| Базовый seed | 2024 | фиксированное значение |

Если серия выполняется долго, параметры можно уменьшить: интерфейс
показывает оценку числа запусков и прогресс-бар.

## 6. Seed и воспроизводимость

Seed повтора вычисляется детерминированно:

```
seed_повтора = (базовый_seed + (повтор + 1) · 7919) mod 2^32
```

Одинаковые параметры серии и базовый seed дают одинаковые числа при повторном
запуске (проверяется тестом `test_experiment_is_reproducible`). Значения
`seed` сохраняются в CSV для каждой строки.

## 7. Порядок проведения

1. Выберите вид эксперимента и схему (или текущую схему из конструктора).
2. Задайте сетку вероятностей (или глубину) и вероятность ошибки.
3. Установите shots, число повторов и базовый seed.
4. Нажмите «Выполнить серию» и дождитесь завершения.
5. Посмотрите график: точки — средние, отрезки — 95 % ДИ, пунктир — шумовой
   уровень.
6. Сохраните CSV (все запуски и средние) и PNG.
7. Сформулируйте вывод самостоятельно, опираясь на числа.

## 8. Как интерпретировать результаты

- Если кривая лежит **выше** пунктира и растёт с параметром, отклонение
  связано с ошибками, а не только со случайностью выборки.
- Если кривая **на уровне** пунктира, эффект неразличим при данных `shots`:
  увеличьте `shots` или число повторов.
- Широкие доверительные интервалы означают, что точек или повторов мало.
- Разные наклоны кривых в эксперименте сравнения — наблюдаемый факт, а не
  заранее заданный результат.
- Плоская кривая phase-flip для состояния Белла — ожидаемое следствие
  измерения в Z-базисе; для схемы с `H` после ошибки она перестаёт быть
  плоской.

## 9. Формат CSV

Сырые данные (`experiment_<вид>.csv`):

| Столбец | Смысл |
|---|---|
| Вид эксперимента | название серии |
| Серия | кривая (канал ошибки или фиксированный канал для глубины) |
| Параметр | значение `p` или число операций |
| Повтор | номер повтора (с 1) |
| TVD | метрика в этом запуске |
| Шумовой уровень | TVD идеальной выборки в этом запуске |
| Целевая вероятность | частота целевой строки (если задана) |
| shots | число измерений |
| seed | seed этого запуска |

Средние (`experiment_<вид>_mean.csv`): серия, параметр, средний TVD,
стандартное отклонение, границы 95 % ДИ, шумовой уровень, средняя целевая
вероятность, число повторов.

Файлы в кодировке UTF-8 с BOM: русские заголовки корректно открываются в
Excel. Первая строка начинается с `#` и содержит параметры серии.

## 10. Ограничения методики

- Оценка TVD по конечному числу измерений смещена вверх: даже идеальная
  выборка даёт TVD порядка 0,01–0,04 при 1000 shots. Поэтому в каждой серии
  показан шумовой уровень.
- Число повторов (10) даёт широкие доверительные интервалы; для более
  точных оценок его нужно увеличить.
- Модели ошибок паулиевские и неоднородностью кубитов не обладают; выводы
  относятся к модели, а не к конкретному устройству.
- Глубина — число слоёв операций, а не физическое время; сравнение с
  реальными устройствами требует калибровочных данных.
- Серия использует одну и ту же схему; эффекты других схем (например, с
  фазочувствительными вентилями) могут отличаться.

## 11. Готовые результаты

В каталоге `examples/results/` лежат реальные файлы, полученные
`scripts/generate_examples.py` (состояние Белла, shots = 1000, seed = 2024,
10 повторов):

- `experiment_bitflip.csv` / `.png` — рост TVD до ≈ 0,31 при p = 0,2;
- `experiment_readout.csv` — аналогичный рост для ошибки считывания;
- `experiment_depth.csv` / `.png` — рост TVD от ≈ 0,04 до ≈ 0,35 при
  увеличении числа операций от 2 до 20;
- `experiment_compare.csv` / `.png` — три кривые: bit-flip и readout растут,
  phase-flip остаётся на уровне шума для состояния Белла;
- `run_bell_ideal.csv`, `run_bell_noisy.csv`, `comparison_bell_noise.png` —
  распределения одного запуска.

Эти числа — результат выполнения программы, а не нарисованные вручную
иллюстрации. Их можно воспроизвести: `python scripts/generate_examples.py`.
